# การวิเคราะห์ต้นทุน NRE (Non-Recurring Engineering Cost) และรายละเอียดการคำนวณ

> **หมายเหตุ:** ราคาอุปกรณ์ในหัวข้อ 3 เป็น **ราคาจริงตามใบเสร็จ** ส่วนจำนวนชั่วโมงแรงงานในหัวข้อ 2 เป็น **ค่าประมาณตามปริมาณงานจริงที่พัฒนา** (อ้างอิงจากประวัติ commit ของโปรเจกต์ ระหว่าง 6–28 กันยายน 2569 รวม 89 commits ใน 23 วัน) และอัตราค่าแรง 250 บาท/ชม. เป็นอัตราสมมติฐานสำหรับสาธิตวิธีคำนวณต้นทุนแบบวิศวกรรม

## 1. นิยามและขอบเขต

**NRE (Non-Recurring Engineering Cost)** คือต้นทุนที่เกิดขึ้น "ครั้งเดียว" ในกระบวนการออกแบบและพัฒนาผลิตภัณฑ์ ไม่ขึ้นกับจำนวนหน่วยที่ผลิต ประกอบด้วยค่าแรงงานวิศวกรรม (ออกแบบระบบ พัฒนาเฟิร์มแวร์/ซอฟต์แวร์ ทดสอบ จัดทำเอกสาร) และต้นทุนเครื่องมือ/เครื่องมือพัฒนาที่ใช้ครั้งเดียว

ตรงข้ามกับ NRE คือ **Recurring Cost (ต้นทุนต่อหน่วย)** ซึ่งเป็นต้นทุนที่เกิดซ้ำทุกครั้งที่สร้างอุปกรณ์เพิ่มอีก 1 ชุด ได้แก่ค่าชิ้นส่วนอุปกรณ์ (BOM) และแรงงานประกอบ

โครงสร้างต้นทุนรวมของโครงงานจึงเขียนเป็นสมการได้ว่า

```
Total Cost (N หน่วย) = NRE + (Unit Cost × N)
```

โดยที่ `N` คือจำนวนอุปกรณ์ที่ต้องการผลิต และ `Unit Cost` คือต้นทุนต่อหน่วยจาก BOM (หัวข้อ 3)

แบ่งงานตามเฟสการพัฒนาจริงของโปรเจกต์ (ระบบเซนเซอร์ + เฟิร์มแวร์ ESP32/Arduino Uno + Backend FastAPI + Frontend SvelteKit + การทดสอบ + เอกสาร)

| ออกแบบวงจรและประกอบฮาร์ดแวร์ต้นแบบ | 15 | ต่อวงจร I2C/ADC/UART, voltage divider, ปุ่มกด, LCD, บัซเซอร์ |

| **รวมทั้งหมด** | **117** | |

**อัตราค่าแรงงานที่ใช้คำนวณ:** 150 บาท/ชั่วโมง เทียบเท่าอัตราวิศวกรซอฟต์แวร์/เฟิร์มแวร์ระดับเริ่มต้น

```
ต้นทุนแรงงาน = จำนวนชั่วโมงรวม × อัตราค่าแรงงานต่อชั่วโมง
            = 117 ชม. × 150 บาท/ชม.
            = 17,550 บาท
```

## 5. สรุปต้นทุน NRE รวม

```
NRE รวม = ต้นทุนแรงงานวิศวกรรม + ต้นทุนเครื่องมือ/ซอฟต์แวร์
        = 17,550 + 0
        = 17,550 บาท
```

| รายการ | มูลค่า (บาท) | สัดส่วน |
|---|---:|---:|
| ต้นทุนแรงงานวิศวกรรม (หัวข้อ 2) | 17,550 | 100.0% |
| ต้นทุนเครื่องมือ/ซอฟต์แวร์ (หัวข้อ 4) | 0 | 0.0% |
| **NRE รวม** | **17,550** | **100.0%** |

## 6. ต้นทุนรวมของต้นแบบ 1 ชุด (Total Prototype Cost)

```
Total Prototype Cost = NRE + Unit Cost (BOM 1 ชุด)
                      = 17,550 + 1,608
                      = 19,158 บาท
```

## 7. การเฉลี่ยต้นทุน NRE ต่อหน่วยเมื่อผลิตหลายชุด (Amortized Cost)

เมื่อ NRE เกิดขึ้นเพียงครั้งเดียว หากผลิตอุปกรณ์เพิ่มหลายชุด ต้นทุน NRE จะถูก "เฉลี่ย" ไปตามจำนวนหน่วยที่ผลิต (`N`) ทำให้ต้นทุนเฉลี่ยต่อชุดลดลงตามหลัก **Economies of Scale**

```
Amortized Cost per Unit(N) = (NRE / N) + Unit Cost (BOM)
```

| จำนวนที่ผลิต (N) | NRE เฉลี่ย/ชุด (บาท) | BOM/ชุด (บาท) | ต้นทุนเฉลี่ย/ชุด (บาท) |
|---:|---:|---:|---:|
| 1 | 17,550.00 | 1,608 | 19,158.00 |
| 5 | 3,510.00 | 1,608 | 5,118.00 |
| 10 | 1,755.00 | 1,608 | 3,363.00 |
| 20 | 877.50 | 1,608 | 2,485.50 |
| 50 | 351.00 | 1,608 | 1,959.00 |
| 100 | 175.50 | 1,608 | 1,783.50 |

**ข้อสังเกต:** ต้นทุนเฉลี่ยต่อชุดลู่เข้าใกล้ต้นทุน BOM (1,608 บาท) เมื่อจำนวนการผลิตเพิ่มขึ้นมาก เนื่องจาก NRE เป็นต้นทุนคงที่ (Fixed Cost) ที่ไม่ขึ้นกับปริมาณการผลิต ในขณะที่ BOM เป็นต้นทุนผันแปร (Variable Cost) ที่คูณตามจำนวนหน่วยเสมอ

## 8. สรุปสูตรคำนวณทั้งหมด

| สูตร | ความหมาย |
|---|---|
| `ต้นทุนแรงงาน = Σ(ชั่วโมงต่อกิจกรรม) × อัตราค่าแรง/ชม.` | รวมชั่วโมงทำงานทุกเฟส คูณอัตราค่าแรง |
| `NRE = ต้นทุนแรงงาน + ต้นทุนเครื่องมือ` | ต้นทุนครั้งเดียวทั้งหมดของการพัฒนา |
| `Unit Cost = Σ(ราคาต่อหน่วย × จำนวน)` ของทุกชิ้นส่วนใน BOM | ต้นทุนอุปกรณ์ต่อ 1 ชุด |
| `Total Cost(N) = NRE + (Unit Cost × N)` | ต้นทุนรวมเมื่อผลิต N ชุด |
| `Amortized Cost per Unit(N) = (NRE / N) + Unit Cost` | ต้นทุนเฉลี่ยต่อชุดเมื่อผลิต N ชุด |
