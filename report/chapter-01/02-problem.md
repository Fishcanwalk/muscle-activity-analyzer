# 1.2 ปัญหาที่ต้องการแก้ไข

ปัญหาหลักคือข้อมูลจากเซนเซอร์มีรูปแบบและอัตราการอ่านต่างกัน ข้อมูล sEMG และ FSR ต้องอ่านถี่และต่อเนื่อง ขณะที่ข้อมูลอุณหภูมิเปลี่ยนช้ากว่า ส่วนข้อมูลจาก IMU และสัญญาณชีพต้องอ่านจากบัส I2C เดียวกัน นอกจากนี้ข้อมูลต้องเดินทางจาก Uno ไป ESP32 แล้วจึงไปยังเว็บโดยไม่ทำให้ลูปอ่านเซนเซอร์ค้าง

ในส่วนซอฟต์แวร์ยังต้องจัดการการเชื่อมต่อที่อาจหลุด การส่งข้อมูลแบบสด การบันทึกเฉพาะช่วงที่ทำเซต และการเก็บข้อมูลให้ผูกกับผู้ใช้และเซสชันได้ถูกต้อง
