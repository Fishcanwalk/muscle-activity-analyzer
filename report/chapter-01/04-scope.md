# 1.4 ขอบเขตของระบบและงานที่ดำเนินการ

## ขอบเขตที่ทำในรายงานนี้

- Arduino Uno อ่าน ADC ช่อง A0 และ A1 ด้วย Timer1 กับ ADC interrupt แล้วส่งค่าออกทาง Hardware Serial
- ESP32 รับข้อมูลจาก Uno ทาง `Serial2`, อ่านเซนเซอร์ I2C, รับปุ่มด้วย GPIO interrupt, จัดการงานด้วย FreeRTOS และส่ง HTTP telemetry
- Frontend รับข้อมูลที่ `/api/telemetry`, กระจายข้อมูลผ่าน `/api/telemetry/stream`, จัดการการบันทึกและการปรับเทียบ และแสดงผลการฝึก
- Backend ใช้ FastAPI ตรวจสอบผู้ใช้ รับ telemetry ผลเซสชัน และ calibration ก่อนเก็บลง MongoDB

## สิ่งที่ไม่ควรตีความเกินขอบเขต

ค่าที่คำนวณจากเซนเซอร์เป็นค่าประมาณเพื่อใช้ติดตามการฝึก โดยเฉพาะ SpO2 และค่าที่แปลงจาก ADC เป็นหน่วยทางกายภาพ ส่วนข้อมูลกล้องใช้ช่วยนับและประเมินท่าทางในเว็บ ไม่ได้แทนการตรวจวัดทางการแพทย์

แหล่งข้อมูล: `README.md`, `PINS.md`, โค้ดใน `backend/`, `frontend/` และสองโฟลเดอร์ Arduino ที่ระบุในรายงาน
