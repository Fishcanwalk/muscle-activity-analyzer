# 1.3 วัตถุประสงค์ของโครงงาน

1. รับค่า sEMG และ FSR จาก Arduino Uno แล้วส่งต่อให้ ESP32 ด้วย UART
2. อ่านข้อมูล MPU6050/MPU6500, MAX30102 และ MLX90614 ผ่าน I2C บน ESP32
3. ประมวลผลข้อมูลเบื้องต้น เช่น ความนิ่งของ FSR, ความเร็ว, อัตราการเต้นหัวใจ และอุณหภูมิ
4. ส่ง telemetry ไปยังเว็บเพื่อแสดงผลแบบสดและส่งต่อไปยัง FastAPI
5. รองรับการปรับเทียบ การเริ่ม/หยุดบันทึก และการเก็บผลการฝึกใน MongoDB
6. แยกโค้ดและเอกสารให้ตรวจสอบเส้นทางข้อมูลและแก้ปัญหาหน้างานได้ง่าย
