# 2.3 ความต้องการด้านการทำงานและข้อกำหนดอื่นของระบบ

## ความต้องการด้านการทำงาน

1. อ่านค่าเซนเซอร์และส่งข้อมูลต่อเนื่องตามรอบที่กำหนด
2. รับ telemetry จาก ESP32 และแสดงผลสดผ่าน SSE
3. เริ่มและหยุดการบันทึกตามเซสชัน พร้อมจำกัดการบันทึกไม่ให้ข้ามผู้ใช้
4. ปรับเทียบค่า EMG และ FSR แบบผูกกับผู้ใช้
5. ลงทะเบียน เข้าสู่ระบบ ต่ออายุ token และตรวจสอบสิทธิ์ก่อนใช้ข้อมูลส่วนตัว
6. บันทึกผลรายเซตและค้นผลย้อนหลังตามผู้ใช้หรือ session id

## ข้อกำหนดอื่น

- UART ระหว่าง Uno กับ ESP32 ต้องใช้ baud rate และระดับแรงดันที่ถูกต้อง
- I2C ต้องใช้ขา SDA/SCL และ address ตามการต่อจริง
- การทำงานที่มีเวลาคงที่ควรไม่ถูกบล็อกจาก HTTP หรือการแสดงผล
- ต้องมีการตรวจสอบข้อมูลผิดรูปแบบและรับมือการเชื่อมต่อหลุด
- ค่าที่เป็นค่าประมาณต้องระบุข้อจำกัดก่อนนำไปตีความ
