# บทคัดย่อ

โครงงานนี้พัฒนาระบบติดตามการออกกำลังกายที่รวมข้อมูลจาก sEMG, FSR, MPU6050/MPU6500, MAX30102 และ MLX90614 เข้าด้วยกัน โดย Arduino Uno อ่านค่า sEMG และ FSR ผ่าน ADC แล้วส่งข้อมูลให้ ESP32 ด้วย UART ส่วน ESP32 อ่านเซนเซอร์ I2C ประมวลผลเบื้องต้น และส่ง telemetry ผ่าน Wi-Fi ไปยังเว็บแอป

ฝั่งเว็บรับข้อมูลแบบสดด้วย SvelteKit กระจายข้อมูลผ่าน Server-Sent Events (SSE) และส่งข้อมูลที่เหมาะสมต่อไปยัง FastAPI เพื่อเก็บใน MongoDB ระบบยังรองรับการเริ่มและหยุดบันทึก การปรับเทียบเซนเซอร์ การสรุปผลรายเซต และการส่งออกข้อมูลเป็น CSV หรือ JSON

ผลลัพธ์ของการพัฒนาคือโครงสร้างการทำงานที่แยกหน้าที่ชัดเจนระหว่างอุปกรณ์อ่านเซนเซอร์ เว็บ และ API อย่างไรก็ตาม ค่าบางส่วน เช่น SpO2 และแรงจาก FSR เป็นค่าประมาณ จึงควรใช้เพื่อดูแนวโน้มการฝึก ไม่ใช่การวัดทางการแพทย์หรือการสอบเทียบห้องปฏิบัติการ
